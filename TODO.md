### P0: correctness and safety

- [x] **P0-1. A Capstone the bindings are not for is refused.** Before: against 5.0.9 and 6.0.0-Alpha11 everything compiled and linked, then printed garbage with exit 0 or segfaulted.
  - Build time: `private/config.nim` asks pkg-config; `raw.nim` stops with "Capstone X is not supported".
  - Run time: `cs_open` returns `CS_ERR_VERSION` when `cs_version()` disagrees with the bindings; `initCapstone` raises with both versions in the message. This replaced the first sketch (abort at module init): no import-time side effect, and it is the error code Capstone reserves for bindings.
  - `nim check` and nimsuggest never run external programs: there pkg-config is skipped and the v5 bindings are assumed, or `-d:capstoneMajor`.
- [x] **P0-2. Header check:** `private/abi_check.c` is compiled into every build that knows the include flags and asserts API version, `sizeof(cs_insn)`, `sizeof(cs_detail)`, `CS_OP_MEM`, `CS_OP_FP` and three `*_INS_ENDING` sentinels. `-d:capstoneNoHeaderCheck` turns it off.
- [x] **P0-3. Link configuration:** pkg-config at compile time, its own message plus an install hint on failure; `-d:capstoneLibs` / `-d:capstoneMajor` / `-d:capstoneCflags` replace it; `-d:capstoneStatic` links `libcapstone.a`.
- [x] **P0-4.** `cs_regs_access` takes `var cs_regs`; a `let` array no longer compiles.
- [x] **P0-5.** `cs_disasm_ex` is not exported.
- [x] **P0-6.** `cs_vsnprintf_t` and `cs_opt_mem` declared by hand with the `va_list` parameter; `tests/tmem.nim` runs Capstone through a `vsnprintf` written in Nim.

| R11 | 84 macros missing | `cmacros.nim`: 79 x86 flag constants, `CS_SUPPORT_*`, `CS_MAKE_VERSION`, `CS_INSN_OFFSET`, `X86_REL_ADDR`; values checked against the headers by `tests/tmacros.nim` |

## Working notes

- To test against another Capstone: `PKG_CONFIG_PATH=<prefix>/lib/pkgconfig LD_LIBRARY_PATH=<prefix>/lib nimble test`.
- `--nimbleDir` does not isolate nimble: 0.26.2 builds binary packages (Futhark's `opir`) under the configured nimble dir. For an isolated run set `XDG_CONFIG_HOME=<scratch>/xdg` with `<scratch>/xdg/nimble/nimble.ini` containing `nimbleDir = r"<scratch>/nimble"`.
- Scratch material from this work is under `/tmp/lcn/` and will not survive a reboot. Worth knowing about: Capstone 5.0.9 and 6.0.0-Alpha11 builds (`/tmp/lcn/CapstoneNewer/prefix-5`, `prefix-6`), a MinGW build of 5.0.9 (`/tmp/lcn/mingw/prefix`), an isolated Futhark 0.16.1 install (`/tmp/lcn/FutharkRegen/nimble`), Nim 2.0.16 (`/tmp/lcn/nim20`), and the ABI comparison of v4 / v5 / v6 (`/tmp/lcn/CapstoneNewer/abi/tables.txt`).
